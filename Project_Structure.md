# Week 3 – Advanced Cybersecurity Practical

## Project Overview

This project documents the Week 3 Advanced Cybersecurity Practical performed in an authorized laboratory environment.

The project covers network discovery, Nmap security assessment, Wireshark traffic analysis, vulnerability assessment, and security hardening.

## Objectives

- Discover active hosts and network services
- Identify open ports and services using Nmap
- Perform advanced Nmap scanning
- Capture and analyze network traffic using Wireshark
- Investigate network communication
- Identify security weaknesses
- Apply security hardening measures
- Compare security posture before and after hardening

## Tasks Covered

### Task 7 – Network Discovery & Basic Nmap Scanning

Network configuration, host discovery, open ports, and services were identified using Nmap.

### Task 8 – Advanced Nmap Security Assessment

Advanced scanning techniques were used for:

- Service and version detection
- OS detection
- TCP SYN scanning
- UDP scanning
- NSE vulnerability investigation

### Task 9 – Wireshark Network Traffic Capture

Network traffic was captured and analyzed using Wireshark.

Protocols investigated included:

- DNS
- TCP
- UDP
- ICMP
- ARP
- HTTP

### Task 10 – Nmap + Wireshark Investigation

Nmap scan traffic was captured in Wireshark and analyzed using TCP SYN, SYN/ACK, and RST packets.

### Task 11 – Advanced Network Traffic Investigation

Network conversations, endpoints, protocols, ports, DNS traffic, and possible unusual traffic patterns were investigated.

### Task 12 – Vulnerability Assessment

Security findings were identified and documented with:

- Severity
- Evidence
- Security impact
- Recommendations

### Task 13 – Security Hardening

Security improvements were applied to reduce the attack surface.

Examples include:

- Disabling unnecessary services
- Closing unused ports
- Restricting network exposure
- Firewall configuration
- Software updates
- Security configuration improvements

### Task 14 – Final Mini Security Assessment

The final assessment combined:

- Network discovery
- Traffic analysis
- Vulnerability assessment
- Security hardening
- Before/after verification
